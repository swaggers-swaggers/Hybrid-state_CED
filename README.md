# Hybrid-State CED · Qwen3.5-0.8B

本项目研究单出口提前解码：完整执行到第 12 层后，先用一个小网络判断置信度；只有置信度足够高，才乘冻结词表矩阵生成输出 token，并用三个独立投影器补写第 16、20、24 层的 KV。被跳过深层 GDN 的递归状态和卷积状态保持不变。

核心假设是：可以在第 12 层可靠预测的 token，可能不需要深层 GDN 再吸收其信息。预测容易是否意味着可以省略记忆写入，需要单独验证。已完成单出口开销测试与模型运行校验：强制第 12 层退出的配对中位加速约 1.82×。网络与投影器尚未训练，质量与真实自适应退出率仍未验证。README 是唯一维护的项目说明。

## 架构与执行顺序

使用本地 `models/Qwen3.5-0.8B-Base` 文本主干。层号从 1 开始：24 个 block，隐藏维度 1024，词表 248320；full attention 为 4、8、12、16、20、24 层，其余为 GDN。唯一检测位置是第 12 个完整 block 的残差输出，包含 attention、MLP 及残差更新，对应代码索引 11。

```text
输入当前 token x_t
  → block 1…12 → h12
  → 唯一置信度网络 C(h12) → q
      q < τ：继续 block 13…24 → 原最终 Norm → 冻结词表 → 下一 token
      q ≥ τ：h12 × M12 → 冻结词表 → 下一 token
              ├─ P16(h12) → 补写第 16 层当前位置 KV
              ├─ P20(h12) → 补写第 20 层当前位置 KV
              └─ P24(h12) → 补写第 24 层当前位置 KV
              深层 GDN 状态保持；缓存补写完成后进入下一 decode 步
```

### 先判置信度，再读词表

置信度网络暂定 `Linear(1024,128) → SiLU → Linear(128,1) → sigmoid`，只输入 h12，不输入词表 logits、Top-k、熵或 teacher 结果。默认阈值 `τ=0.9` 只是接口占位，尚未校准。

低置信度路径不执行 M12、不计算第 12 层的词表 logits、不运行三个 KV 投影器，而是继续主干。高置信度路径才计算 `logits = (h12 @ M12) @ W_vocab.T` 并 greedy 选一个 token。M12 为 1024×1024 的可训练读出矩阵，当前初始化为单位阵；它不是另一个出口。原共享大词表 W_vocab 冻结，原模型主干、嵌入和最终 Norm 同样冻结。当前推理开销实验关闭所有梯度，后续训练时可训练置信网络、M12 和三个投影器。

不需要先计算大词表来判断置信度，也不使用跨层候选一致性。当前没有 Top-k 规则或多出口分支。Python 控制器将置信度取回 CPU 后作判断，此同步等待计入开销。

### 三个独立 KV 投影器

| 模块 | 唯一特征输入 | 对应目标 |
|---|---|---|
| P16 | 第 12 层完整输出 h12 | 第 16 层待追加的 K/V |
| P20 | 第 12 层完整输出 h12 | 第 20 层待追加的 K/V |
| P24 | 第 12 层完整输出 h12 | 第 24 层待追加的 K/V |

三个模块一一对应、参数互不共享。每个模块是两组无偏置 `1024→512` 线性映射，接口为 `KVProjector(h12) → (K_raw, V)`；输入 `[B,1,1024]`，两个输出各 `[B,1,512]`。不输入其他层隐藏状态、目标层隐藏状态或历史 KV，也不先施加目标层 input_layernorm。

写缓存时，K/V 整理为 `[B,2,1,256]`；K 经过目标层 KNorm 与当前绝对位置的部分 RoPE，V 不旋转。每个目标层只追加当前位置一次，不覆盖历史条目。占位初始化复制目标层原 K/V 投影权重，仅用于测计算形状，不能视为已经学到 h12 到目标 KV 的映射。

处理 x_t 的 h12 预测的是 x_(t+1)，补写的是已处理位置 t 的 KV。第 12 层自身的 KV 已正常写入，不重复投影。第 13、14、15、17、18、19、21、22、23 层 GDN 的递归状态 S、卷积缓存 C 及状态标志均保持；不移位、不补零、不衰减。后续若运行深层，从保留状态处理当前输入，不重放跳过的 token。

## 开销实验

prefill 与首个输出 token 都走完整模型，并排除在计时之外。完整 prefill 最后位置的原生输出头已经产生 token 1；计时从“输入 token 1，生成 token 2”开始，默认连续生成 64 个后续 token，至 token 65，不因 EOS 提前停止。

| 场景 | 用途 | 第 12 层的动作 |
|---|---|---|
| `full` | 完整模型基线 | 不调用置信度网络，完整运行 24 层 |
| `gate_reject` | 测拒绝退出的额外成本 | 调用网络并同步分数，强制拒绝，不读中间词表，继续至 24 层 |
| `exit_12` | 测接受退出的全部成本 | 调用网络并同步分数，强制接受，再读词表并补写三个目标 KV |
| `adaptive_12`，默认关闭 | 检查网络控制的混合路径 | 根据网络分数与阈值实际选择；未训练时不能解释为有效策略 |

固定接受/拒绝仅用于分别计量两条路径，均执行同一个置信网络。它们不是置信度准确性实验。配置 `include_adaptive=true` 可加入按网络分数分支的诊断；当前随机初始化的网络没有质量或覆盖率结论，不把这组结果当作训练后的加速收益。

每组使用相同 prompt、首 token 和独立复制的前缀缓存；随后各自自由 greedy 生成。prefill、首 token、缓存复制和预热不进入主计时。未训练模块的续写可能无意义，此轮只测执行成本。

主指标为整段同步后的 wall time/token，包含实际主干、置信网络、CPU 决策同步、接受后的 M12 与词表、三个投影器、KNorm/RoPE、缓存追加、greedy 选择及 Python 调度。另记录整段 GPU 时间跨度和独立分项 profile。主计时只使用一对总 GPU events；分项诊断另跑，避免大量事件影响主要结果。P95 为“每轮整段平均耗时”的 P95，不是逐 token 尾延迟。峰值显存包含全部常驻模块及框架持有的前缀副本，不等于单请求部署显存。

默认 batch=1、BF16、SDPA，上下文 256/2048，每种长度 3 个固定文本片段，每个 prompt 下 5 轮随机顺序比较 3 组，每组 64 个计时步骤，共 **5,760 步**。另有 144 步预热和 144 步分项诊断。本次完整流程实际用时 **70.3 秒**，其中主计时合计 **58.27 秒**；启动前的预算为 3–8 分钟，实际耗时以本机当前后端为准。启用 adaptive 后为 7,680 个主计时步骤，该配置本次未运行。

### 实测结果 2026 年 9 月 19 日

运行目录：[20260919-115122](results/exit_cost/20260919-115122/)。完整流程退出码 0，结果状态 PASS。RTX 5060 Ti 16GB，PyTorch 2.11.0+cu130、Transformers 5.12.1、BF16、SDPA；GDN 使用 torch recurrent 路径。启动前未见其他模型计算进程，桌面进程仍有少量 GPU 占用。

主计时从生成输出 token 2 开始；每种长度下每组 15 次完整测量（3 个 prompt × 5 次重复），共 90 次、5,760 个 token 步。配对加速比使用同一 prompt/轮次的完整模型基线，表中为各配对加速比的中位数。

| 上下文 | 场景 | 平均 ms/token | 平均 tokens/s | 配对中位加速 |
|---:|---|---:|---:|---:|
| 256 | `full` | 11.713 | 85.38 | 1.000× |
| 256 | `gate_reject` | 11.889 | 84.12 | 0.987× |
| 256 | `exit_12` | 6.431 | 155.51 | 1.820× |
| 2048 | `full` | 12.031 | 83.19 | 1.000× |
| 2048 | `gate_reject` | 12.067 | 82.89 | 0.993× |
| 2048 | `exit_12` | 6.565 | 152.41 | 1.821× |

强制第 12 层退出时，两个长度下的配对中位耗时下降分别为 **45.06%** 和 **45.10%**。不退出时，相比完整基线的平均额外耗时分别为 **0.176 ms（1.50%）** 和 **0.036 ms（0.30%）**；2048 上下文下逐对差值有正有负，微小开销受运行波动影响，不应宣称其精确为零。

独立分项诊断（每个场景/长度 3 个 prompt，各 8 步）的平均 GPU 时间跨度如下：

| 退出路径分项 | 256 上下文 ms/token | 2048 上下文 ms/token |
|---|---:|---:|
| 置信网络 + 决策同步 | 0.074 | 0.104 |
| M12 读出矩阵 | 0.030 | 0.026 |
| 冻结词表乘法 | 1.237 | 1.254 |
| 三个 KV 投影器合计 | 0.033 | 0.036 |
| KV 格式转换、KNorm/RoPE 与追加 | 0.080 | 0.124 |

三个投影器连同格式转换和写入合计约 **0.113–0.160 ms/token**；词表读出仍是新增模块中较大的成本。分项测量包含大量事件和调度开销，且只采样短段，不能将这些数值相加来替代主计时，也不能据此给出精确的 kernel 占比。

6 组运行时校验均 PASS：完整及拒绝路径与原生 logits/缓存一致；置信度判断先于词表；拒绝时不运行中间读出和投影器；接受时只执行前 12 层并调用三个目标投影器；attention KV 长度增长正确；跳过 GDN 的 S/C 和标志不变；可恢复完整一步；K-only RoPE 与原生实现一致。

本次结论是：在这套 batch=1、BF16、SDPA、torch GDN 实现下，第 12 层退出存在明确的计算成本收益，置信网络和三个 KV 投影器没有抵消省去深层 block 的收益。该结论来自未训练占位模块及强制接受/拒绝两条路径；**不是已实现 1.82× 的高质量自适应推理**。未测试学习后的置信度覆盖率、生成质量、长程 GDN 省略写入损失、批处理或其他优化后端。

如果仅按两条路径实测平均耗时做线性估算，且假定混合退出不会改变单步成本，25% 的接受率对应约 1.11–1.13×，50% 对应约 1.28–1.29×。这只是算术外推，既不是混合路径实测，也不是准确率保证；下一步应训练 M12、置信网络与三个投影器，再在质量约束下评估实际接受率。

## 后续训练与验证

1. 冻结主干和词表，训练 M12；在完整 teacher 的相同前缀上用下一 token CE 与蒸馏监督。置信网络学习该出口预测是否可靠，监督标签可离线使用 teacher；在线输入始终仅为 h12。
2. 用真实目标层 raw K/V 监督三个独立投影器，验证 KNorm/RoPE 后的缓存及后续 logits；单层误差小不能替代三层联合续写检验。
3. 独立校准置信度阈值，报告错误退出率与覆盖率。用真实 KV 的诊断对照隔离 GDN 省略写入损失，再检查投影 KV 和 GDN 保持的联合质量。
4. 用学生自己生成的前缀检验连续早退、恢复深层执行、长文本漂移；在质量约束下测包含全部开销的速度，不能仅凭平均执行层数推断加速。
