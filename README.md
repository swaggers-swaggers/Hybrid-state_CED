# Hybrid-State CED · Qwen3.5-0.8B

本项目研究单出口提前解码：完整执行到第 12 层后，先用一个小网络判断置信度；只有置信度足够高，才乘冻结词表矩阵生成输出 token，并用三个独立投影器补写第 16、20、24 层的 KV。被跳过深层 GDN 的递归状态和卷积状态保持不变。

核心假设是：可以在第 12 层可靠预测的 token，可能不需要深层 GDN 再吸收其信息。预测容易是否意味着可以省略记忆写入，需要单独验证。已完成单出口开销测试与模型运行校验：强制第 12 层退出的配对中位加速约 1.82×。已完成 smoke、pilot 和原模型生成数据追加训练。新增自然语料已按每段 100 万累计训练 600 万有效 token：首段完成后又接续五段，诊断测试出口一致率达到 37.33%，KV 平均归一化误差降至 0.1314。但六段校准均无合格阈值，自适应退出率为 0%，尚未获得质量合格的加速。新增 1,000 万有效 token 数据中，余下 400 万尚未训练。README 是唯一维护的项目说明。

## 架构与执行顺序

使用本地 `models/Qwen3.5-0.8B-Base` 文本主干。层号从 1 开始：24 个 block，隐藏维度 1024，词表 248320；full attention 为 4、8、12、16、20、24 层，其余为 GDN。唯一检测位置是第 12 个完整 block 的残差输出，包含 attention、MLP 及残差更新，对应代码索引 11。

```text
输入当前 token x_t
  → block 1…12 → h12
  → 唯一置信度网络 C(h12) → q
      q < τ：继续 block 13…24 → 原最终 Norm → 冻结词表 → 下一 token
      q ≥ τ：h12 × M12 → 冻结词表 → 下一 token
              ├─ P16(h12) → 补写第 16 层当前位置 KV
              ├─ P20(h12) → 补写第 20 层当前位置 KV
              └─ P24(h12) → 补写第 24 层当前位置 KV
              深层 GDN 状态保持；缓存补写完成后进入下一 decode 步
```

### 先判置信度，再读词表

置信度网络暂定 `Linear(1024,128) → SiLU → Linear(128,1) → sigmoid`，只输入 h12，不输入词表 logits、Top-k、熵或 teacher 结果。开销入口默认阈值 `τ=0.9` 是接口占位；训练评估使用独立校准结果。已执行各轮都未找到合格阈值，因此关闭自适应退出。

低置信度路径不执行 M12、不计算第 12 层的词表 logits、不运行三个 KV 投影器，而是继续主干。高置信度路径才计算 `logits = (h12 @ M12) @ W_vocab.T` 并 greedy 选一个 token。M12 为 1024×1024 的可训练读出矩阵，初始化为单位阵；它不是另一个出口。原共享大词表 W_vocab 冻结，原模型主干、嵌入和最终 Norm 同样冻结。推理开销实验关闭所有梯度；训练入口仅更新置信网络、M12 和三个投影器。

不需要先计算大词表来判断置信度，也不使用跨层候选一致性。当前没有 Top-k 规则或多出口分支。Python 控制器将置信度取回 CPU 后作判断，此同步等待计入开销。

### 三个独立 KV 投影器

| 模块 | 唯一特征输入 | 对应目标 |
|---|---|---|
| P16 | 第 12 层完整输出 h12 | 第 16 层待追加的 K/V |
| P20 | 第 12 层完整输出 h12 | 第 20 层待追加的 K/V |
| P24 | 第 12 层完整输出 h12 | 第 24 层待追加的 K/V |

三个模块一一对应、参数互不共享。每个模块是两组无偏置 `1024→512` 线性映射，接口为 `KVProjector(h12) → (K_raw, V)`；输入 `[B,1,1024]`，两个输出各 `[B,1,512]`。不输入其他层隐藏状态、目标层隐藏状态或历史 KV，也不先施加目标层 input_layernorm。

写缓存时，K/V 整理为 `[B,2,1,256]`；K 经过目标层 KNorm 与当前绝对位置的部分 RoPE，V 不旋转。每个目标层只追加当前位置一次，不覆盖历史条目。占位初始化复制目标层原 K/V 投影权重，仅用于测计算形状，不能视为已经学到 h12 到目标 KV 的映射。

处理 x_t 的 h12 预测的是 x_(t+1)，补写的是已处理位置 t 的 KV。第 12 层自身的 KV 已正常写入，不重复投影。第 13、14、15、17、18、19、21、22、23 层 GDN 的递归状态 S、卷积缓存 C 及状态标志均保持；不移位、不补零、不衰减。后续若运行深层，从保留状态处理当前输入，不重放跳过的 token。

## 开销实验

prefill 与首个输出 token 都走完整模型，并排除在计时之外。完整 prefill 最后位置的原生输出头已经产生 token 1；计时从“输入 token 1，生成 token 2”开始，默认连续生成 64 个后续 token，至 token 65，不因 EOS 提前停止。

| 场景 | 用途 | 第 12 层的动作 |
|---|---|---|
| `full` | 完整模型基线 | 不调用置信度网络，完整运行 24 层 |
| `gate_reject` | 测拒绝退出的额外成本 | 调用网络并同步分数，强制拒绝，不读中间词表，继续至 24 层 |
| `exit_12` | 测接受退出的全部成本 | 调用网络并同步分数，强制接受，再读词表并补写三个目标 KV |
| `adaptive_12`，默认关闭 | 检查网络控制的混合路径 | 根据网络分数与阈值实际选择；未训练时不能解释为有效策略 |

固定接受/拒绝仅用于分别计量两条路径，均执行同一个置信网络。它们不是置信度准确性实验。配置 `include_adaptive=true` 可加入按网络分数分支的诊断；该开销测试使用的随机初始化网络没有质量或覆盖率结论，不把这组结果当作训练后的加速收益。

每组使用相同 prompt、首 token 和独立复制的前缀缓存；随后各自自由 greedy 生成。prefill、首 token、缓存复制和预热不进入主计时。未训练模块的续写可能无意义，此轮只测执行成本。

主指标为整段同步后的 wall time/token，包含实际主干、置信网络、CPU 决策同步、接受后的 M12 与词表、三个投影器、KNorm/RoPE、缓存追加、greedy 选择及 Python 调度。另记录整段 GPU 时间跨度和独立分项 profile。主计时只使用一对总 GPU events；分项诊断另跑，避免大量事件影响主要结果。P95 为“每轮整段平均耗时”的 P95，不是逐 token 尾延迟。峰值显存包含全部常驻模块及框架持有的前缀副本，不等于单请求部署显存。

默认 batch=1、BF16、SDPA，上下文 256/2048，每种长度 3 个固定文本片段，每个 prompt 下 5 轮随机顺序比较 3 组，每组 64 个计时步骤，共 **5,760 步**。另有 144 步预热和 144 步分项诊断。本次完整流程实际用时 **70.3 秒**，其中主计时合计 **58.27 秒**；启动前的预算为 3–8 分钟，实际耗时以本机当前后端为准。启用 adaptive 后为 7,680 个主计时步骤，该配置本次未运行。

本次结论是：在这套 batch=1、BF16、SDPA、torch GDN 实现下，第 12 层退出存在明确的计算成本收益，置信网络和三个 KV 投影器没有抵消省去深层 block 的收益。该结论来自未训练占位模块及强制接受/拒绝两条路径；**不是已实现 1.82× 的高质量自适应推理**。未测试学习后的置信度覆盖率、生成质量、长程 GDN 省略写入损失、批处理或其他优化后端。

## 模块训练与验证

训练对象只有 M12、P16/P20/P24 和 C(h12)，共 **4,325,633 个参数**。主干、嵌入、词表矩阵和原模型所有 Norm 冻结。模型仍只有第 12 层一个出口；推理仍先判断置信度，再按需读词表、补写 KV，深层 GDN 不更新。监督数据由完整冻结模型在线产生，不需要人工标注。

本次实现的是**监督预训练 → 置信度训练 → 独立阈值校准 → 续写验证**。训练阶段的 teacher 始终完整执行；GDN 保持和投影 KV 的闭环效应在验证阶段测量。本轮没有实现带梯度的多步 rollout 微调，也不以单步投影误差代替长期能力验证。

### 训练目标与损失

**第一阶段：M12 与三个独立投影器。** 完整 teacher 前向提取第 12 个完整 block 的残差输出 h12、最终 Norm 后的隐藏状态，以及目标层实际 `k_proj/v_proj` 输出。捕获线性层的真实输出意味着标签已经使用目标 attention 的 post-input-layernorm 输入，K 标签位于 KNorm/RoPE 之前。首个训练批及每个开发、校准、测试数据读取阶段，会把标签经过 KNorm/RoPE/head reshape 后与 teacher 实际缓存逐项核对，失败立即停止。

读出损失为：

```text
p12 = softmax(W_vocab · M12 · h12)       # 代码采用列向量记号
L_readout = CE(p12, 数据中的下一 token)
          + T² KL(p_teacher,T || p12,T)
T = 1，两个系数均为 1
```

teacher 与学生比较同一个文本前缀。CE 约束真实文本预测；KL 约束完整模型的分布。词表权重不更新，但不能将学生词表计算放入 no_grad，否则 M12 收不到梯度。完整词表按 **16 个位置一块**计算损失、按实际位置数加权累积梯度；不缓存全数据词表 logits，不用 Top-k 近似替代完整 KL。

三个投影器的损失为：

```text
E_l,K / E_l,V = 训练集合前 32 个选中窗口中，teacher 对应 raw K/V 的平均平方值
L_KV = (1/6) Σ_{l∈{16,20,24}} [ MSE(P_l,K(h12), K_l) / max(E_l,K, 1e-8)
                              + MSE(P_l,V(h12), V_l) / max(E_l,V, 1e-8) ]
L_modules = L_readout + L_KV
```

归一化尺度仅从训练集估计，之后固定并随 checkpoint 保存；六项等权，防止某层数值量级独占损失。这里优化的是 raw KV 的恢复，是否能维持后续 logits 必须通过续写验证回答。

M12 初始化为单位阵；三个投影器复制各目标层原 K/V 权重作为起点。AdamW，模块学习率 `1e-4`，weight decay `0.01`，梯度裁剪 `1.0`，3% warmup 后余弦衰减到 10% 学习率。batch=2×256，主干 BF16、训练参数 FP32、矩阵运算 BF16、损失 FP32。每 512 步及末尾开发评估，按开发集 `CE + KL + 平均归一化 KV 误差` 选择 checkpoint；初始参数也进入比较，若训练退化则保留初始最佳值并如实记录。默认 2,048 个 optimizer step。

**第二阶段：唯一置信度网络 C(h12)。** 固定已经选出的 M12 和投影器，在独立置信度训练窗口上生成：

```text
y_conf = 1[argmax(p12) == argmax(p_teacher)]
L_conf = BCEWithLogits(C(h12), y_conf)
```

C 仍为 `1024→128→1`，只输入 h12。标签阶段离线计算两个词表输出；线上拒绝路径不会因此计算中间词表。网络学习的是“与完整模型下一 token 一致的可能性”，不是真实答案正确率，也不是“跳过 GDN 一定安全”的概率。使用不加类别权重的 BCE，避免直接扭曲后验分数；学习率 `3e-4`，batch=1024，最多 5 epoch，按开发 BCE 选择。只在 CPU 暂存这阶段 h12 与二元标签，pilot 约 255 MiB，结束释放。

**第三阶段：校准。** 固定所有权重，在独立 calibration 窗口上扫描预先规定的阈值列表。选择经验 teacher 分歧率不超过 **1%**、接受数至少 **1,024** 时覆盖率最高的阈值；没有合格值就记录 `NO_ELIGIBLE_THRESHOLD`，评估时关闭早退。阈值不会根据 test 自动调整。token 相互相关，且存在阈值搜索，这不是统计上保证 1% 风险的证书。

### 训练后怎样验证

`evaluate` 必须读取校准后的 checkpoint，并执行以下检查：

1. **单模块质量：** next-token CE、teacher CE、完整分布 KL、Top-1 一致率，三个目标各自 K/V 归一化误差；置信度 BCE、Brier、固定阈值覆盖率和接受 token 的 teacher 分歧率。
2. **同前缀闭环：** 上下文 256/2048，各 4 个 test 片段，继续 64 步。每步给 teacher 与学生输入相同真实文本 token，报告 KL、NLL/PPL 比、退出率、错误退出率，特别记录恢复深层执行时的 KL。
3. **隔离状态误差：** 固定“连续早退 4 次、完整执行 1 次”的节奏，比较真实 KV+正常 GDN、投影 KV+正常 GDN、真实 KV+保持 GDN、投影 KV+保持 GDN。真实状态来自该分支当前历史下的完整 shadow 前向，属于诊断 oracle；其计算不作为加速结果。真实 KV+正常 GDN 对照额外核对恢复后的整个缓存与 shadow 一致。另跑真实置信网络驱动的混合路径。
4. **自由续写与速度：** 同一完整 prefill 生成首 token，完整模型与自适应学生随后分别 greedy 生成 64 个 token，保存文本/token 和实际退出次数。计时从生成 token 2 开始，包含 gate、词表、投影和缓存更新；预热、复制缓存、诊断 shadow 均在计时外。每对顺序打乱，但仅 8 对，属于初步速度诊断，不能替代充分重复的正式性能实验。

进入更大规模实验的暂定条件：接受 token 的 teacher 分歧率 ≤1%、覆盖率 ≥25%、同前缀 PPL 增幅 ≤3%，同时自由续写没有明显退化，再确认真实自适应加速 ≥1.10×。报告保留各上下文和对照结果，不自动将完成运行标成“模型能力 PASS”。若真实 KV+保持 GDN 仍显著恶化，应先重新审视省略 GDN 写入的假设；若主要是投影 KV 恶化，再考虑短 rollout 的功能性损失微调。

smoke 训练窗口只有 256，闭环验证到 2048 上下文和 64 步；更长续写、中文及任务准确率仍需后续独立实验。置信头没有深层跳过历史输入，无法直接感知深层状态已积累多少偏差，这是当前架构必须通过闭环数据检验的限制。

### KV 与 GDN 的状态影响

固定节奏为“早退四步、完整一步”，每个上下文 4 个片段、各 64 步；总共每片段 52 次强制早退、12 次恢复深层执行。下表只看**恢复完整计算时**与相同文本前缀 teacher 的平均 KL，避免差的出口词表预测掩盖状态误差。

| 深层状态对照 | 上下文 256 | 上下文 2048 |
|---|---:|---:|
| 真实 KV + 正常更新 GDN | 0.0000 | 0.0000 |
| 投影 KV + 正常更新 GDN | 0.1917 | 0.0201 |
| 真实 KV + 保持 GDN | 0.5811 | 0.8911 |
| 投影 KV + 保持 GDN | 0.8271 | 1.0167 |

两轮主模块均选第 2,048 步，置信头均选第 5 epoch；checkpoint 中的 4,325,633 个辅助参数均为有限值。追加训练初始开发指标与 pilot 选中 checkpoint 的开发指标**逐项完全一致**，训练/留出窗口和 KV 归一化尺度一致，确认实际继承了 pilot 主模块。训练源文件哈希在结束审计时均匹配，原模型权重保持冻结。各阶段 PyTorch allocated 峰值最高约 **1,997 MiB（1.95 GiB）**，出现在原模型数据生成阶段；不包含整卡其他进程和 CUDA 保留开销。

### 同一自然文本诊断测试集的对比

两轮均使用相同 128 个窗口、32,640 个预测位置，完整 teacher 的 CE 均为 3.2614。

| 指标 | pilot | 生成数据追加训练后 |
|---|---:|---:|
| 出口 CE，越低越好 | 7.4174 | 7.0017 |
| teacher→出口 KL，越低越好 | 4.3268 | 3.9584 |
| 出口与 teacher Top-1 一致率 | 18.78% | **24.51%** |
| 六项 raw KV 平均归一化 MSE | 0.4253 | **0.3528** |
| 独立校准合格阈值 | 无 | 无 |
| 自适应退出率 | 0% | 0% |

追加训练后一致率提高 **5.73 个百分点**，平均 KV 误差下降 **17.05%**。三个目标层的 K/V 六项误差都下降。说明这次继续训练改善了读出与投影，但出口 CE 仍明显高于完整 teacher，没有达到可靠早退要求。

这两轮对比没有同等计算量的自然文本继续训练对照，并且追加训练保留 256-token 提示后在生成段上监督，输入长度变为 512。因此只能归纳为“本次生成数据继续训练后改善”，不能归因于“生成数据优于同预算自然数据”。smoke 的 test 窗口数也不同，不把跨 smoke/pilot 的变化当作严格同集对照。

### 为什么仍然没有合格阈值

校准集均为 65,280 个位置；原规则保持为 teacher 分歧率 ≤1% 且接受数 ≥1,024。下表是预先规定的阈值扫描结果，不用于事后放宽规则。

| 阈值 | pilot 接受数 / 分歧率 | 追加训练接受数 / 分歧率 |
|---|---:|---:|
| 0.80 | 1,407 / 14.71% | 2,555 / 11.98% |
| 0.85 | 666 / 11.41% | 1,431 / 9.29% |
| 0.90 | 192 / 9.90% | 527 / 7.21% |
| 0.96 | 1 / 0% | 19 / 0% |

高分样本有所增加，但样本量足够的阈值仍远高于 1% 分歧率；极高阈值下只有极少量样本，不能据此声称可靠退出。两轮都输出 `NO_ELIGIBLE_THRESHOLD`，没有改变阈值网格、风险或最小接受数。

置信头 test BCE 从 0.3291 变为 0.3877；两轮正例比例与正误标签已经改变，不能仅靠这个 BCE 数字断言排序能力下降。对当前目标更有意义的是校准集中固定阈值的分歧率/接受数以及最终有没有满足风险约束。

### 投影改善没有消除 GDN 保持的影响

以下仍使用固定的“四次强制早退、一次完整计算”节奏，比较恢复完整计算时的平均 KL。每种长度 4 个固定片段，每片段 12 次恢复计算。

| 状态对照 | pilot，256 | 追加训练，256 | pilot，2048 | 追加训练，2048 |
|---|---:|---:|---:|---:|
| 真实 KV + 正常更新 GDN | 0.0000 | 0.0000 | 0.0000 | 0.0000 |
| 投影 KV + 正常更新 GDN | 0.1499 | 0.1081 | 0.0191 | 0.0162 |
| 真实 KV + 保持 GDN | 0.5811 | 0.5811 | 0.8911 | 0.8911 |
| 投影 KV + 保持 GDN | 0.8268 | 0.7926 | 1.0004 | 0.9849 |

投影训练改善能传递到恢复深层后的 logits，但 GDN 保持仍有较大影响。真实 KV + 保持 GDN 对照不依赖本次辅助模块权重，在同样输入/退出节奏下数值相同是预期结果。该对照仍是强制退出、没有筛选高置信容易 token，不能直接否定选择性跳过 GDN 的假设；也不能由 raw KV 的 MSE 下降直接推断全模型能力达标。

### 自由续写与速度

两轮均因校准失败而全部拒绝早退；每轮 8 对、512 个计时 token 的自由续写都与完整模型逐 token 相同，同前缀 KL 为 0。这验证了完整模型回退路径，**未验证有实际退出时的质量**。

| 轮次 / 上下文 | 完整模型平均 ms/token | 自适应全部拒绝平均 ms/token | 配对中位加速 |
|---|---:|---:|---:|
| pilot / 256 | 12.363 | 12.714 | 0.978× |
| pilot / 2048 | 12.445 | 12.534 | 0.988× |
| 追加训练 / 256 | 11.966 | 12.040 | 0.996× |
| 追加训练 / 2048 | 11.847 | 12.008 | 0.985× |

每种长度仅 4 对测试，轮次间绝对速度受运行环境波动影响，不应解释为蒸馏带来加速。当前没有质量合格的自适应加速；开销实验中强制退出约 1.82× 的结论仍只描述成本上限附近的路径收益。

本次优先结论是：更多主模块训练及本次生成数据继续训练均产生了可测改善，但可靠出口预测、置信度风险控制与 GDN 状态省略仍未同时达标。下一步设计应围绕这些未通过的条件，而不是直接以强制早退速度作为模型效果。

## 每轮 100 万有效 token 的继续训练

第一段使用新增 1,000 万语料中的**有效预测位置 `[0,1000000)`，精确 1,000,000 个位置，1 epoch**。从生成数据追加训练选定的 `results/training/20260919-175254-pilot-distillation/distilled/modules/modules.pt` 继续 M12 和三个投影器。原模型、词表、架构、CE/KL/KV 权重和学习率保持；重建 AdamW 与余弦学习率调度，沿用原 KV 尺度。置信头按更新后的出口重新收集独立标签、训练和校准。

训练入口 `scripts/run_incremental_training.py` 一次只执行一段主模块训练以及后续置信头/校准/评估，不自动推进下一段。`--chunk-index` 从 0 开始；相邻段按有效标签编号划分，边界窗口可能作为上下文重复读取，但监督位置不会重复。首段涉及窗口索引 0–3921，共 3,922 窗口，最后窗口只启用 145 个标签；batch=2，共 1,961 个 optimizer step。

主模块只在训练前记录基线、在 100 万位置全部完成后计算开发指标，中间不做周期性开发评估。主训练结束后再进行置信头训练、独立阈值校准、同前缀状态对照和自由续写。训练期间日志只落盘，不人工查看进度或调参；整轮结束统一分析。沿用相同 dev/calibration/test 窗口和风险标准，便于逐段比较。用户随后授权接续 500 万，已串行执行第 2–6 段，五段全部结束后才统一读取指标；每段保持完整四阶段流程。当前没有正在运行的训练。

## 接续 500 万实测：第 2–6 段

运行目录：[20260919-225836-continue-5m](results/training/20260919-225836-continue-5m/)。从首段选定权重继续，精确消费有效预测位置 **`[1000000,6000000)`**，新增 **5,000,000** 个监督位置，累计使用该新增语料 **600 万**。五段各自执行主模块训练、置信网络训练、校准和最终评估，20 个阶段全部退出码 0；总耗时 **3,392.22 秒（56 分 32 秒）**，共 **9,808 个主模块 optimizer step**。运行期间没有读取进度或根据中途指标调整训练。

### 置信度仍是实际退出的直接限制

五段均为 `NO_ELIGIBLE_THRESHOLD`，阈值为空。规则保持分歧率 ≤1%、接受数 ≥1,024。最终校准集 65,280 个位置上的部分曲线：

| 阈值 | 接受数 | 覆盖率 | 与 teacher 的分歧率 |
|---|---:|---:|---:|
| 0.80 | 4,306 | 6.596% | 13.73% |
| 0.85 | 2,544 | 3.897% | 12.70% |
| 0.90 | 1,152 | 1.765% | 11.11% |
| 0.94 | 417 | 0.639% | 6.71% |
| 0.96 | 205 | 0.314% | 4.39% |
| 0.98 | 62 | 0.095% | 3.23% |
| 0.99 | 10 | 0.015% | 0.00% |

阈值 0.9 虽已接受 1,152 个位置，但 128 个与 teacher 不一致，分歧率 **11.11%**；阈值 0.99 虽零分歧，却仅 10 个位置，仍不够。最终置信头测试 BCE / Brier 为 **0.4998 / 0.1678**，本轮起点为 0.4449 / 0.1474；出口标签和正例比例随读出训练改变，不能只凭跨轮 BCE 增加断言置信排序退化。但当前校准证据明确不支持启用早退。

**37.33% 是与完整模型下一 token 的一致率，不是早退率，也不是真实任务答案准确率。**

### 投影误差下降与 GDN 保持的影响

固定“四次强制退出、一次完整执行”，每个上下文长度 4 个片段。下表比较恢复完整计算时的平均 KL：

| 状态对照 | 起点，256 | 最终，256 | 起点，2048 | 最终，2048 |
|---|---:|---:|---:|---:|
| 真实 KV + 正常 GDN | 0.0000 | 0.0000 | 0.0000 | 0.0000 |
| 投影 KV + 正常 GDN | 0.0490 | 0.0128 | 0.0138 | 0.0077 |
| 真实 KV + 保持 GDN | 0.5811 | 0.5811 | 0.8911 | 0.8911 |
| 投影 KV + 保持 GDN | 0.7494 | 0.6766 | 0.9687 | 0.9521 |

正常更新 GDN 时，投影对后续 logits 的干扰继续减小；按实际架构保持 GDN 后，联合误差的改善幅度有限，尤其在 2048 上下文。此处退出由固定日程强制安排，不能直接否定“只跳过低信息 token”的假设，也不能当作置信筛选后闭环质量的证据。

### 运行正确性与速度

五段的运行校验均 PASS。因校准失败，全部自适应测试关闭早退：同前缀 KL=0、PPL 比=1；五段合计 40 对自由续写都与对应完整模型逐 token 相同，2,560 个计时步骤均没有早退。最终段的速度：

| 上下文 | 完整模型 ms/token | 自适应回退 ms/token | 配对中位加速 |
|---|---:|---:|---:|
| 256 | 12.186 | 12.335 | 0.991× |
| 2048 | 12.187 | 12.355 | 0.987× |

本轮仍没有实现有效加速。每段每长度只有 4 对速度样本；文本相同只验证完整计算回退路径，不能证明提前退出后的生成质量。

完成后的核验确认：五段监督区间连续且不重复；各段的训练前开发指标与上一段所选 checkpoint 的开发指标一致；KV 归一化尺度和 gate/dev/calibration/test 索引保持；源代码及源权重哈希匹配；主模块仅在该段最后一步执行开发评估；每段均选中了最后一步主模块和第 5 epoch 置信网络；所有保存的辅助参数均为有限值，日志没有异常或非有限数值。PyTorch allocated 显存峰值约 **1,882 MiB**，不代表整卡总占用。

每段继承 M12 与三个投影器，重建优化器、学习率调度和置信网络，这是既有分段协议；本轮没有修改模型架构、损失权重或阈值要求。当前观察支持“继续增加自然语料仍可改善读出与 KV 投影”，但未解决可靠置信筛选及深层 GDN 跳过写入后的质量验证。沿用的英语 test 已参与项目探索，这些是诊断结果，不能作独立泛化结论。
