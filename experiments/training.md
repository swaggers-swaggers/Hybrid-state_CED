# 双样本共享参数与多步 KV 蒸馏

目标仍是改善第 12 层检测头在所有有效位置的输出分布。常规流程为 `modules → confidence → evaluate`；不测推理开销，不验证 GDN 偏差，不用 KV 数值对齐损失。

## 数据与参数来源

数据保持为已审计的 teacher Top-8 稀疏数据；第 j 行 logits 对应 `prompt + y[:j]` 对 `y[j]` 的预测。输入 `y[j-1]`，监督第 j 行。prompt、首个生成位置、padding 不计损失。EOS 按数据 mask 计入。全词表 student logits 只在 GPU 临时使用，不写入数据集。

默认继承 `results/training/20260923-detector-1h/experiment/confidence.pt`，包括 M12、P16/P20/P24、置信网络所有权重；逐项校验与来源相等。累计已训练区间 `[0,643275)`，下一轮从 643275 开始。优化器重建，模块不重新初始化。语义标识为 `top8_shared_batch_multistep64_v3`；已知来源允许显式迁移，当前语义 checkpoint 仍要求配置、模型和数据身份一致。来源阈值不沿用。

## 三类损失

teacher 的 8 个候选各成一类，其余词表合为第九类。使用保存的全词表 logsumexp 计算概率；student 在同一组 ID 上聚合。默认 `T=1`；数据也保存了 `T=2` 统计，损失按 `T² KL(p⁹∥q⁹)` 计算。

1. **M12**：所有有效位置的检测头九类 KL 均值。是否可信、是否投影，不影响检测头的输出或梯度。
2. **P16/P20/P24**：当前处于可发起投影的状态、`Top8 overlap ≥ 6 OR Top1 match`、且有后续位置时，仅用 h12 投影当前 K/V，早退的深层 GDN 保持。随后 `H=min(64, 回答/所选训练区间剩余位置数)` 个位置全部输入 teacher token 并完整执行。每个位置都计算完整输出九类 KL，其梯度经缓存和冻结深层网络传回本次投影。全部实际监督位置求均值，无 KV MSE。
3. **C**：在独立 gate 集学习上述 OR 标签，用 BCEWithLogits。继承已有参数，训练后按 dev BCE 选择，初始权重也作为候选。置信网络不能筛掉检测头训练和评估样本。

M12 / P / C 学习率分别为 `1e-4 / 1e-5 / 3e-4`。M12、P 使用独立 fused AdamW，weight decay 0.01，梯度裁剪 1。M12 按两条回答有效位置总数归一化梯度，P 按两条回答的后续监督位置总数归一化；不能把长度不同的回答简单各取均值后除以二。无投影监督的批次不 step P，也不施加其 weight decay。C 默认 batch 1024、5 epoch。

## 64 个后续位置的精确定义

这是一次投影后连续多步的训练展开，不是每隔 64 个绝对位置统一截断。投影落在计算块末尾时仍然可以监督到后面第 64 个位置；第 64 步损失反向后才结束这段梯度范围。每 8 步的激活重算边界不会截断图。

同一条回答在这段展开内不再插入新投影，64 步结束后才能在下一个符合条件的位置发起下一段。这样每个投影的后续监督范围明确，也延续了“投影后下一步强制完整执行”的要求。检测头在这 64 个完整步同样输出并训练。该训练策略还没有覆盖连续多次早退之间的交互，也不等同于自由生成验证；其目的为训练投影对后续输出的影响。

短回答或本轮数据区间末尾按实际剩余位置监督，末位置不投影。图结束时保留 student 缓存值并 detach，不拿 teacher 深层缓存修复。损失在 detach 前计算。不同样本各自独立控制展开和截断，一条样本结束不会截断另一条的图。

## 双样本批量训练与显存

- 同一个主模型、同一份辅助参数，batch 维同时放两条不同回答。无需启动第二份模型或两个竞争 CUDA 资源的训练进程。两个样本的损失梯度汇总后才更新参数，绝不在缓存图仍用于反向时 step。
- 每条回答的 prefix 独立完整 prefill；合并后仅对 full-attention KV 左侧补零并显式 mask。GDN 状态按 batch 维拼接，RoPE 使用各自真实绝对位置。生成尾部 padding 没有损失，不能污染另一条样本；最后不足两条时允许单样本。
- 冻结前 12 层每次处理每条 32 个 token；检测头词表对有效位置成块读出。两条回答的深层逐步运算采用 batch=2，使小矩阵乘法变大。
- 深层每 8 步 activation checkpoint。重算函数使用显式缓存张量输入/输出，卷积状态更新前复制，避免重算修改保存的输入。GDN recurrent state 用赋值替代原位覆盖。缓存图跨重算段保持连接。
- 仅存在一条主模型参数副本。显存主要新增两个样本的缓存与重算边界状态；深层未承担监督的位置跳过最终词表读出。不能仅凭 batch=2 保证 UTL 达到某个数值，实际吞吐要在后续获准的训练中确认。64 步监督本身也比单步监督增加计算。

参数见 `response_batch_size=2`、`projection_horizon=64`、`checkpoint_steps=8`、`readout_chunk_size=32`。实现入口为 `ced_distill/batched.py`；`training.py` 保留公共数据转换和置信训练，`evaluation.py` 继续无条件评估检测头。

## 评估与执行

主训练前后在同一个 dev 子集比较检测头 Top1 一致率、Top8 重合分布、九类 KL、Top8 内部条件 KL、teacher token NLL、尾部质量误差；最终 test 不按置信筛选。置信网络另报告 BCE。它们是 teacher 前缀下的输出分布指标，不是自由生成任务准确率。

训练日志分别记录 `kv_projections`（投影次数）、`kv_supervised_positions`（多步监督位置数）、`rollout_full_kl`、`response_batches` 和两类参数的更新次数；不再用一步监督对数解释多步数据量。

默认 `scripts/train_top8_distill.py --plan` 不训练。实际训练需 `--run`，输出目录必须全新；`--verify` 禁用 optimizer 更新，仅检查正确性。后续如获准限时训练，由内部预算按最初 1024 个位置的吞吐估算 token 数；只能在两条回答均完成后结束主训练，不在反向图中途存续训 checkpoint。到达软件时间预算可能延迟至本批结束，外层硬截止仍是最终保护。检测头计数是本轮数据消耗区间，P 后续监督位置数另记，不能混为训练 token 总数。

`scripts/run_top8_bounded.py` 支持主模块、整个 worker 与外层硬截止。运行期间不主动查看进度，结束后统一汇总。辅助产物每次运行最多 2 GB、至少保留 20 GB 可用空间；不增加 teacher 全词表数据。
