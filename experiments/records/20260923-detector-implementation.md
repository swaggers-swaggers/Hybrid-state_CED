# 2026-09-23 检测头指标与训练实现校验

本次完成代码和文档调整，未启动正式续训，未改变已有训练权重，未测推理开销。

## 当前实验选择

- 每个有效位置都输出 block 12 检测头分布并参与梯度下降。
- 投影触发及置信监督标签为 `Top8 overlap ≥6 OR Top1 相同`，没有 KL 截止条件。
- 主评估直接读取检测头，报告训练前后的同一 dev 集指标以及 test 集指标；置信网络不筛选位置。常规流程不再执行校准和推理开销评估。
- 源权重是 2026-09-23 已完成 50 万位置训练的 `calibrated.pt`；M12、三个投影器和置信头均已精确继承，默认接续位置为 500,000。
- 冻结浅层和检测头按默认 32 个位置分块；KV 更新和下一步完整输出的反向传播维持时间顺序。

## 已完成检查

21 项 CPU 检查通过，覆盖 OR 条件两条独立分支、KL 大仍允许合格、拒绝位置仍有检测头梯度、批量/逐位置梯度一致、数据区间对齐、时间预算、置信头继承等。

真实 GPU 检查：[verification.json](../../results/verification/20260923-detector-chunked/verification.json)。

- 拆分完整路径相对原生完整路径的两次 logits 最大误差均为 0。
- 更改分块中的未来 token，前半部分输出最大变化为 0，因果性检查通过。
- BF16 分块与逐步执行在 34 个位置上，h12 相对范数差约 1.081%，九类检测头 KL 的最大差约 0.01599。分块数值不是逐项严格相等；这是工程检查中的浮点实现差异，不是训练质量提升。
- 在合成标签下运行真实训练循环，34 个有效位置只做 2 次浅层分块和 2 次检测头分块；包含一个不可信位置和跨 32 位置边界的完整监督对。
- 33 个候选产生 16 个完整投影监督对，读出矩阵和六个 K/V 权重张量都有非零、有限梯度；主干没有梯度。
- 优化器替换为不更新参数的测试对象，所有辅助权重检查前后完全相同，实际更新次数 0，未保存训练权重。
- 强制置信阈值接受全部/拒绝全部时，检测头评估结果相同，验证指标确实覆盖全部位置。

本次未量化训练吞吐或 GPU 利用率的提升，也没有新的正式训练效果。后续运行应先看 `detector_before/after/delta` 的实际分布一致性变化，再讨论实验是否有效。
